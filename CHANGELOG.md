### Added
- CounterStrikeSharp plugin with three movement presets: `csgo`, `surf`, `vanilla`.
- Console commands `csgomove_apply`, `csgomove_toggle`, `csgomove_status`.
- Profile reapplied automatically on map start.
- Standalone `.cfg` presets mirroring the plugin profiles.
- `docs/why-it-works.md` explaining the subtick levers, backed by static reverse engineering.
- CI workflow building the plugin on every push and pull request.
